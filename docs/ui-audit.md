# UI Audit

## Round A — UX
- 開いて1タップ以内で問題を解けるか
- モード選択が先に来ていないか
- 回答後の次アクションが2つ以内か

## Round B — Learning
- 正解演出よりMemory Hookが強いか
- 点の暗記だけになっていないか
- Historyへの遷移が自然か

## Round C — Mobile
- 390pxで長い選手名が破綻しないか
- 主要操作44px以上か
- 下部ナビと回答ボタンが競合しないか

## Round D — Extreme states
必ずテスト:
- 画像なし
- 画像URL切れ
- 長い選手名
- 同姓同名
- 長期在籍
- 監督途中交代
- 複数回在籍
- 回答履歴0
- 1000問以上回答済み
- 低速回線
- JavaScriptエラー時の最低限表示

## Round E — Visual
- 赤を使いすぎていないか
- 何でもカード化していないか
- 年代が視覚的主役になっているか
- スポーツ速報サイト化していないか

## Pass criteria
すべての主要画面について「何をする画面か」を3秒で説明できること。
