# UI 05 — Visual System

## Direction
Archive × Editorial × Football

## Color
- Background: off-white / neutral
- Text: near black
- Brand accent: Urawa-like red, limited use
- Correct: independent positive state color
- Wrong: independent error state color

※正確なクラブCI色を利用する場合は公式ガイドライン確認後に決定。

## Typography
- Year: oversized display type
- Question: bold but compact
- Supporting copy: readable Japanese sans-serif
- Metadata: small, restrained

## Shape
- Card乱用禁止
- Border / spacing / typographyで階層を作る
- 大きな角丸はQuiz optionなど操作要素に限定
- shadowは原則不要

## Motion
- answer feedback: 小さく短い変化
- confetti禁止
- page transitionは控えめ
