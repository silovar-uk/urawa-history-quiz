# UI 01 — Experience

## Primary jobs

### Open and answer immediately
アプリを開いたら、モード選択より先に「今日の1問」が見える。

### Learn one relationship
回答後に、短い Memory Hook を1つだけ表示する。

### Dive into history
回答後から Season / Player / Manager / Kit に自然に遷移できる。

### Return to quiz
History閲覧中も、そのテーマからQuizへ戻れる。

## Core flow

TODAY
→ QUESTION
→ ANSWER
→ MEMORY HOOK
→ NEXT QUESTION

or

MEMORY HOOK
→ SEASON
→ PLAYER / MANAGER / KIT
→ QUIZ THIS TOPIC

## Home principle

ホーム画面をダッシュボード化しない。

優先順:
1. 今日の1問
2. 最近間違えた問題
3. ざっくりした学習状況
4. Historyへの入口
