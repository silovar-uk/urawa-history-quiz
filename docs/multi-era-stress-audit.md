# マルチ年代（1995・2006・2023）ストレステスト監査レポート

## 概要
浦和レッズ歴史クイズアプリにおいて、単一年（2006年）専用設計からマルチ年代（1995年・2006年・2023年）への拡張を実施し、データ構造・出題エンジン・UI表現のストレステストを実施しました。

---

## 監査対象とテストケース

| ケース項目 | 検証内容 | 結果 | 対策・設計 |
| :--- | :--- | :--- | :--- |
| **外国人選手・長音・長名** | 「田中マルクス闘莉王」「アレクサンダー・ショルツ」「マリウス・ホイブラーテン」等での文字あふれ | **PASS** | 390pxスマホ幅で`text-overflow: ellipsis`および適切なフォントサイズを担保 |
| **背番号制度の時代差** | 1995年（変動背番号制・先発1〜11番）で背番号問題が出題可能か | **PASS** | `shirt_number: null` の場合は背番号問題を自動スキップし、ポジション・監督・要約・同時在籍問題にフォールバック |
| **複数年代重複在籍** | 岡野雅行（1995年・2006年の双方に在籍）の扱い | **PASS** | `player_id`（選手マスタ）と`player_seasons`（在籍レコード）を分離したため、選手詳細で複数年代の変遷を正しく表示可能 |
| **同時在籍判定（PLAYER_OVERLAP）** | 特定年代の選手に対し、別年代の選手をディストラクター（誤答）として提示できるか | **PASS** | `coPlayerIds` を排他したプールから他年代の選手を3名選定し、時代混同の誤答を自動生成 |
| **監督交代・複数期在任** | オジェック（1995年）、ブッフバルト（2006年）、スコルジャ（2023年）の区別 | **PASS** | `manager_tenures` で年度と任期を厳密に分離し、年度ごとの指揮官を正確に出題 |
| **年代フィルターの動作** | 1990s / 2000s / 2020s / ALL の切り替え | **PASS** | 選択された年代に応じた出題と学習履歴（localStorage）の蓄積が正常に稼働 |

---

## 結論
1990年代・2000年代・2020年代の3世代を跨いだデータ投入後も、DBスキーマ・Quiz Engine・UIレイアウトは一切破綻せず、安定して稼働することを確認しました。
これにより、1992年のクラブ創設から現在に至る全シーズンへのスケールが可能な基盤が確立されました。
