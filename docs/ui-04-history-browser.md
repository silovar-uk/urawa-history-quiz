# UI 04 — History Browser

## Timeline first

HISTORYの初期画面は年表。
年を選択するとSeason Detailへ。

## Season Detail

優先順:
1. Year
2. League result
3. Short season statement
4. Manager
5. Kit
6. Players
7. Competitions
8. Quiz this season

## Player Detail

- name
- tenure timeline
- position
- shirt number by season
- seasons
- related players
- quiz this player

## Manager Detail

- tenure
- seasons
- major results
- players under manager
- quiz this manager

## Kit Archive

年代ごとにHOME / AWAYを視覚比較できる。
画像は小さなサムネイルにせず、記憶の主役として大きく表示する。
